User guide

From install to trained model

Everything you need: installation, the 3-line quickstart, the CLI, every setting, and the full API.

1 · Install

PyTorch first (CUDA build), then the library.

pip install torch --index-url https://download.pytorch.org/whl/cu121
git clone https://github.com/salim-studio/modetrains.git
cd modetrains
pip install -r requirements.txt
pip install -e .
# optional, for maximum speed
pip install flash-attn --no-build-isolation
pip install liger-kernel

2 · Train (Python)

The fastest path: preset config, fast loader, packed SFT.

from modetrains import ModeTrainsConfig, FastModel, train_sft, save_merged

cfg = ModeTrainsConfig.fast_default("meta-llama/Meta-Llama-3-8B-Instruct", max_seq_length=2048)
model, tok = FastModel.from_pretrained(cfg)
model = FastModel.get_peft_model(model, cfg)

from datasets import Dataset
from modetrains.data import format_alpaca
texts = [format_alpaca("Explain gravity", "", "Mass attracts mass...")] * 100
ds = Dataset.from_dict({"text": texts})

trainer, stats = train_sft(model, tok, ds, cfg, dataset_text_field="text")
save_merged(model, tok, "outputs")

3 · Train & infer (CLI)

No code needed for standard runs.

python -m modetrains info
python -m modetrains train --model meta-llama/Meta-Llama-3-8B-Instruct \
  --data yahma/alpaca-cleaned --steps 60 --out outputs
python -m modetrains infer --model outputs --prompt "What is quantization?"

4 · Configuration

The settings that matter most.

SettingDefaultEffect
model_nameLlama-3-8B-InstructAny causal-LM id from the Hub
max_seq_length2048Context window; larger = more VRAM
load_in_4bittrueNF4 quantization, ~70% less VRAM
packingtrueFill every sequence, up to 2–3x faster
lora.r / alpha16 / 16Adapter capacity (rsLoRA on)
optimadamw_8bit8-bit optimizer state
per_device_batch / grad_accum2 / 4Effective batch of 8 — tune via info
use_liger_kerneltrueFused kernels when installed, ignored otherwise
